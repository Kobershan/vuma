## Multi-Company Split Flow

```
CreateInvoiceCommand(orderId)
  → InvoiceService.GenerateAsync(order)
    → If order.GroupDocumentRef != null:
      → ISplitDocumentBuilder.SplitAsync(order)
        → For each company segment:
          → CreateInvoiceForCompany(companyId, segment)
            → Creates Invoice in company's own database
            → Uses ICompanyDbContextFactory for that company
      → Returns List<Invoice>
    → Else:
      → Creates single Invoice in order's company database
```

## Compliance Rules

1. **No handler touches two databases** — enforced by `MultiCompanyGuardTests`.
2. **Every invoice is entirely within one company's database** — `ICompanyDbContextFactory` per company.
3. **Split reconciliation** — `ISplitDocumentBuilder` asserts line-for-line, cent-for-cent reconciliation.
4. **Pack size snapshot** — Resolved from UoM catalogue at invoice generation, stored immutably.
5. **Analytics never block trade** — Read-only, stale by design (ADR-119).
6. **Company scoping** — Users can only see invoices for their permitted company.
